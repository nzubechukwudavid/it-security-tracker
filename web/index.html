    What this is, and what it assumes

    This is a study plan and job-hunt log for a computer science graduate moving into IT support, networking and eventually security operations. Everything on it is either free or has a free route; the paid items are marked so they can be skipped without breaking the sequence.

    The premise. Security roles are built on top of networking and systems, so the fastest route into security work is to become genuinely employable in IT infrastructure first, then add the security layer while already earning. Applications start in week one, not week sixteen.

    Sixteen weeks at two to three focused hours a day, not seven days at eight. A schedule you can keep for four months beats one you abandon in ten days. The two running tracks at the bottom — the job campaign and the final-year project — are worked on every week, not saved for the end.

    Progress is stored in this browser only. Use Back up after each session and keep the JSON file somewhere safe, or the progress disappears when the browser cache is cleared.

    About the links. Every link was checked against live search results on 5 September 2026, or is the canonical root of a well-established resource. Sites move; if one 404s, search the resource name rather than assuming it is gone.

    Cost. Items marked free need no payment. paid means money is required for the full thing — in most cases a free equivalent sits directly above or below it in the same list.

    Storage. This page saves to browser localStorage. Nothing is uploaded anywhere. If you host it publicly, remember the page is public even though your saved progress is not.
